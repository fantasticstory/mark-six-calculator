# 香港六合彩膽拖／複式比較計算器

直接雙擊根目錄的 `六合彩計算器.html` 使用，單一檔案即可離線執行。亦可使用 `dist/index.html`，但請保留同資料夾內的 `app.js`、`comparison.js`、`engine.js`、`style.css`。無需安裝、登入、網絡或資料庫。修改原始碼後執行 `node build.js` 重新產生單檔版本。

功能包括自訂及預設方案比較（每張卡可獨立設定假設中獎情境）、可修改的七項派彩、逐獎項注數與收入、淨收益及 ROI。手機螢幕可左右滑動卡片作比較。

## 計算方式

每注包含全部膽及從腳選出的 6−膽數個號碼。引擎逐注枚舉，依照 6 正選、5+特別號、5、4+特別號、4、3+特別號、3 分別計算頭至七獎；其餘計為未中獎。沒有把情境答案寫死。大型複式每 40,000 注交還瀏覽器控制權並更新進度，修改輸入會取消舊計算。

派彩設定放在頁首。頭獎預設 8,000,000 元作假設，二、三獎初值為 0，須輸入每全注派彩；頭獎獎金池不等同每全注派彩。四至七獎預設 9,600／640／320／40 元，可修改。半注成本及派彩為全注一半，單式只設全注。收入按每個中獎組合四捨五入至仙後加總。

所有比較卡共用同一組派彩設定。更改相關輸入會清除舊结果；更改派彩會即時重算已有結果（亦可撳「重新計算」確認）。沒有自動讀取即時開彩或派彩，關閉頁面不會保存輸入。

## 驗證

執行 `node tests.js`。測試包括指定七組注數、錯膽案例、實際號碼、半注、ROI、無效輸入，以及窮盡小型投注方案的有效中獎分佈，以獨立組合公式交叉驗證逐注枚舉結果。

規則來源（核對日期：2026-09-20）：

- https://special.hkjc.com/e-win/en-US/betting-info/marksix/prize-qualification/
- https://special.hkjc.com/e-win/zh-HK/betting-info/marksix/allocation-of-prize-fund/

方案比較卡可直接選 1 至 5 膽、自訂腳數／複式號碼數、注額，以及中正選的膽及腳數目（輸入 .5 代表連特別號一齊中，例如 5.5）。每張卡自動枚舉並顯示各獎項、總派彩及盈虧。按「新增自訂方案」可加入更多卡片。
